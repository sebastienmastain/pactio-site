Un script PowerShell sur mesure, testé et documenté

SMSébastien Mastain, administrateur systèmes et réseaux depuis 27 ans · mis à jour le 26/10/2026
En bref

Je développe des scripts PowerShell sur mesure pour les informaticiens et les PME : audits, rapports clients, automatisations Microsoft 365, Intune et Active Directory. Chaque script est testé, documenté, et en lecture seule tant qu'il n'a pas à modifier quelque chose. Devis sur demande.

Vous avez une tâche que vous refaites à la main chez chaque client, ou un audit que les outils du marché ne savent pas faire ? Je peux écrire le script pour vous, avec la même exigence que les outils Pactio.

Ce que je peux faire

  • Audits et inventaires : Microsoft 365, Entra ID, Intune, Active Directory, postes Windows, serveurs.
  • Rapports clients : une note, des constats par priorité, à vos couleurs, en HTML ou PDF.
  • Automatisations : arrivées et départs d'utilisateurs, attribution de licences, nettoyage de comptes, déploiements Intune, tâches planifiées.
  • Dépannage en masse : un correctif à appliquer sur tout un parc, avec un mode simulation avant de toucher à quoi que ce soit.

Comment ça se passe

  1. Vous décrivez le besoin par mail : ce que le script doit faire, l'environnement, le volume.
  2. Je réponds avec un devis : ce qui sera livré, le délai et le prix.
  3. J'écris et je teste le script sur un environnement de test, puis avec vous sur le vôtre si besoin.
  4. Vous recevez le script commenté, sa procédure d'utilisation et, si demandé, le modèle de rapport client.
Mes règles : un script qui modifie quelque chose a toujours un mode simulation ; rien n'est lancé sur votre environnement sans votre accord ; aucune donnée de vos clients ne sort de chez vous.

Questions fréquentes

Combien coûte un script sur mesure ?

Le prix dépend du besoin et du temps de test. Chaque demande reçoit un devis précis avant tout travail.

Le script m'appartient-il ?

Vous pouvez l'utiliser librement dans votre entreprise et chez vos clients. Les conditions exactes sont précisées dans le devis.

Mes données ou celles de mes clients sortent-elles de chez moi ?

Non. Le script se développe et se teste sur un environnement de test ; s'il faut le valider chez vous, c'est avec vous et sur votre accord.

Décrivez votre besoin en quelques lignes, je vous réponds avec un devis.
